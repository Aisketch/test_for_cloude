# MIDOS Platform - Knowledge Base (Filled)

## 1. БІЗНЕС-КОНТЕКСТ

### 1.1 Проект

- **Назва проекту**: MIDOS (MIDOS.io)
- **Слоган/Tagline**: "MIDOS - ваш цифровий близнюк: Масштабуйте експертизу 24/7"
- **Місія**: Повернути експертам творчість - віддавши рутину цифровим двійникам. Надати можливість лідерам думки, консультантам, коучам та професіоналам створювати цифрових близнюків на базі AI, які працюють 24/7, продаючи та консультуючи за вас
- **Конкурент для аналізу**: delphi.ai
- **Унікальна пропозиція (USP)**:
  - Автентичний AI-двійник з 95%+ точністю відтворення особистості
  - Мультимодальність: текст + голос + відео (конкуренти: тільки текст)
  - Швидке навчання: 3-5 днів (vs 4-6 тижнів у конкурентів)
  - Доступніше: $997/міс (vs Delphi $4,500/міс)
  - Корпоративна безпека: SOC 2 Type II сертифіковано

### 1.2 Цільова аудиторія

**Основна ЦА (3 архетипи)**:

1. **Overloaded Expert (Перевантажений Експерт)** - 35-55 років
   - Професія: Коучі/консультанти з 10+ роками досвіду
   - Pain: Робочі тижні 60-70 годин, 200 непрочитаних листів
   - Goal: Work-life balance, масштабування впливу

2. **Scale-Seeking Entrepreneur (Підприємець що Прагне Масштабу)** - 28-40 років
   - Бізнес: Засновники з командами 10-50 осіб
   - Pain: Не можу масштабувати без втрати якості
   - Goal: ROI та конкурентна перевага

3. **Legacy Builder (Будівельник Спадщини)** - 50-70 років
   - Фокус: Збереження знань та менторство
   - Pain: Мої знання помруть зі мною
   - Goal: Створити спадковий актив

**Вторинна ЦА**:
- Цифрові агентства (партнерський канал)
- Освітні платформи (інтеграційні партнери)
- Корпоративні клієнти (Enterprise рівень)

**Pain points (топ-3)**:
1. Repetitive Response Burden: "Відповідаю на одні й ті самі питання 100+ разів щодня" (Тяжкість: 8/10)
2. Scaling Limitations: "Не можу масштабувати експертизу" - обслуговую тільки 10-20 клієнтів, відмовляю 70-80% (Тяжкість: 9/10)
3. Revenue Loss: Втрачений дохід $30K-$70K/рік через відхилених клієнтів

**Jobs to be done (топ-5)**:
1. Автоматизувати доставку експертизи без втрати якості
2. Масштабувати охоплення до 10,000 людей
3. Онбордити клієнтів без 3-5 годин на людину
4. Зменшити повторювану роботу з 80% до 20%
5. Зберегти знання перед виходом на пенсію (для Legacy Builder сегменту)

### 1.3 Бізнес-модель

- **Тип**: SaaS Platform
- **Монетизація**: Підписка (рекурентні платежі)
- **Pricing tiers**:
  - Professional: ~$997/міс
  - Business: ~$1,497/міс
  - Enterprise: ~$2,997/міс
  - (Точні ціни обговорюються індивідуально)

  - Період окупності: 8-12 тижнів

## 2. БРЕНД ТА ВІЗУАЛЬНА ІДЕНТИЧНІСТЬ

### 2.1 Brand Voice & Tone

**Характер бренду**: Професійний + Емпатичний + Інноваційний + Результато-орієнтований

**5 Voice Attributes**:
1. **Direct/Прямий** - Говоримо відкрито про проблеми без прикрас
2. **Empathetic/Емпатичний** - Глибоке розуміння болів експертів
3. **Results-Oriented/Орієнтований на результат** - Конкретні метрики та ROI
4. **Professional/Професійний** - Технічна точність + доступність
5. **Motivational/Мотиваційний** - Апелює до аспірацій та місії

**Tone of voice UA**: Формальне "Ви", прямолінійність, емпатія, конкретні цифри

**Tone of voice EN**: Professional but approachable, results-focused, empowering

**Заборонені слова/фрази**:
- "Робот" / "Bot" (без контексту якості)
- "Замінити вас" (загроза ідентичності)
- "Просто автоматизація" (недооцінює цінність)
- "Дешевий" / "Cheap" (Premium позиціонування)
- Обіцянки без метрик ("найкращий", "ідеальний" без доказів)
