## 1. BRAND IDENTITY (Ідентичність бренду)

### 1.1 Brand Core
- **Brand Name**: MIDOS (MIDOS.io)
- **Tagline/Slogan**: "MIDOS - ваш цифровий близнюк: Масштабуйте експертизу 24/7"
- **Mission Statement**: Повернути експертам творчість - віддавши рутину цифровим двійникам. Ми надаємо можливість лідерам думки, консультантам, коучам та професіоналам створювати цифрових близнюків на базі штучного інтелекту, які працюють цілодобово, продаючи та консультуючи за вас зі збереженням унікального стилю та експертизи фахівця.
- **Vision Statement**: _Інформація не знайдена в наявних файлах_
- **Core Values**:
  1. Автентичність (95%+ рівень відповідності особистості експерта)
  2. Інновації через AI (передові технології GPT-4 Turbo)
  3. Безпека корпоративного рівня (SOC 2 Type II сертифіковано)
  4. Масштабованість без компромісів
  5. Прозорість та етичність використання AI

### 1.2 Brand Personality
- **Archetype**: Creator/Sage (Творець та Мудрець)
- **Personality Traits**:
  1. Інноваційний (передові AI технології)
  2. Професійний (корпоративна безпека та надійність)
  3. Емпатичний (розуміє виклики експертів)
  4. Технологічно просунутий
  5. Орієнтований на результат (ROI 10-30x протягом першого року)
- **Brand Promise**: Автентичний цифровий близнюк, який відтворює ваш голос, особистість та експертизу, працюючи 24/7 без втрати якості

### 1.3 Target Audience

#### Primary Audience (з ICP Segmentation)

**Архетип 1: Overloaded Expert (Перевантажений Експерт)**
- Вік: 35-55 років
- Професія: Коучі/консультанти з 10+ роками досвіду
- Психографія: Шукають work-life balance та можливість масштабувати вплив
- Цінності: Автентичність, досконалість і майстерність (9/10), вплив і значення (10/10)

**Архетип 2: Scale-Seeking Entrepreneur (Підприємець що Прагне Масштабу)**
- Вік: 28-40 років
- Бізнес: Засновники з командами 10-50 осіб
- Психографія: Орієнтовані на дані, висока толерантність до ризиків, швидкі у прийнятті рішень
- Цінності: ROI та конкурентна перевага

**Архетип 3: Legacy Builder (Будівельник Спадщини)**
- Вік: 50-70 років
- Фокус: Збереження знань та менторство
- Психографія: Цінують репутаційну безпеку, низька толерантність до ризиків
- Потреби: Підтримка white-glove implementation

#### Secondary Audience
- Цифрові агентства (партнерський канал)
- Освітні платформи (інтеграційні партнери)
- Корпоративні клієнти (Enterprise рівень)

### Pain Points (з Pain Points Profile v1.0)

**Топ-3 кореневі болі:**
1. **Repetitive Response Burden**: "Відповідаю на одні й ті самі запитання 100+ разів щодня"
   - Тяжкість: 8/10
   - Прояв: робочі тижні 60-70 годин, 200 непрочитаних листів

2. **Scaling Limitations**: "Не можу масштабувати мою експертизу"
   - Тяжкість: 9/10 (НАЙВИЩА)
   - Прояв: Можу обслужити лише 10-20 клієнтів одночасно, відмовляю 70-80% потенційних клієнтів

3. **Revenue Loss**: "Втрачений дохід через відхилених клієнтів"
   - Сума: $30K-$70K щорічно для середнього експерта
   - Вартість бездіяльності: $290K-$350K/рік

**Емоційні драйвери:**
- FOMO (competitors scaling now)
- Страх вигоряння
- Провина перед собою: "Я гаю свій потенціал на зайняту роботу"
- Кореневий драйвер #1: "Чи маю я цінність, якщо мене можна замінити?" (Загроза ідентичності)

## 2. VISUAL IDENTITY (Візуальна система)

### 2.1 Logo System

**Концепція**: Liquid Mercury (Рідкий метал що застиг)
- Логотип фіксує мить, коли рідина перетворилась у форму - кристалізація системи
- Технології, як рідкий метал, плавно адаптуються до користувача

**Варіанти логотипу**:

1. **Vertical Use (Вертикальне)**:
   - Застосування: Веб-сайт (головна, футер), мобільні додатки, соціальні мережі (аватар), презентації (титульна)

2. **Horizontal Use (Горизонтальне)**:
   - Застосування: Email підпис, документація, презентації (хедер), друковані матеріали (візитки)

3. **Symbol Use (Тільки символ)**:
   - Застосування: Favicon, app icon, watermark, малі розміри (менше 32px)

**Кольорові варіації**:
- Повнокольоровий (з металевим ефектом) - основний для цифрових медіа
- Градієнтний (бренд-градієнт) - маркетингові матеріали, соціальні медіа
- Монохромний чорний - документи, чорно-білий друк
- Монохромний білий - темна тема UI, відео, презентації

**Захисна зона**:
- Мінімальна вільна зона дорівнює висоті літери "M" у логотипі
- Застосовується з усіх боків

**Мінімальні розміри**:
- Цифрові медіа: мінімум 32px висотою
- Друк: мінімум 15mm висотою

### 2.2 Brand Mark/Icon

**Символ**: Літера "M" з краплею (ефект рідкого металу)
- **Meaning**: Момент коли рідина перетворюється у фіксовану форму
- **Usage Context**: Favicon, app icon, малі розміри, watermarks

## 4. TYPOGRAPHY (Типографіка)

**Концепція**: Три комплементарні шрифти створюють цілісну систему: гуманістичний для заголовків, чіткий для тексту, креативний для акцентів

### 4.1 Font Families

```css
/* Primary Font (Headings) - Alegreya Sans */
--font-primary: "Alegreya Sans", sans-serif;
/* Weights: 400 (Regular), 600 (Semibold), 700 (Bold) */
/* Source: Google Fonts */
/* Link: https://fonts.google.com/specimen/Alegreya+Sans */
/* Характер: Гуманістичний, відкритий, дружній, технологічний */
/* Використання: Заголовки H1-H3, логотип-супровід, візуальні акценти */

/* Secondary Font (Body) - Inter */
--font-secondary: "Inter", sans-serif;
/* Weights: 400 (Regular), 600 (Semibold) */
/* Source: Google Fonts */
/* Link: https://fonts.google.com/specimen/Inter */
/* Характер: Нейтральний, чіткий, універсальний, оптимізований для екранів */

--font-accent: "Caveat", cursive;
/* Weights: 400 (Regular) */

/* Використання: Обмежено - креативні акценти, емоційні виділення */

/* Body text залишається 16px для читабельності */
```

### 4.4 Typography Rules

**Кольорова типографіка**:

Текст на світлому фоні:
- Основний: `#343a40` (темно-сірий)
- Вторинний: `#6c757d` (середньо-сірий)
- Акцентний: `#0066FF` (Vibrant Blue)

Текст на темному фоні:
- Основний: `#ffffff` (білий)
- Вторинний: `#f1f1f1` (світло-сірий)
- Акцентний: `#7de8ff` (cyan)

Текст на градієнті:
- Завжди білий `#ffffff`
- З тінню: `text-shadow: 0 2px 4px rgba(0,0,0,0.2)`

**Letter Spacing**:
- Tight: -0.02em (для великих заголовків)
- Normal: 0 (стандарт)
- Wide: 0.05em (для малих капсів)

**Line Height**:
- Tight: 1.2 (заголовки H1-H2)
- Normal: 1.5-1.6 (body text)
- Relaxed: 1.8 (спеціальні випадки)

**Max Line Length**: 60-80 символів для оптимальної читабельності

## 8. MOTION & ANIMATION (Анімація)

### 8.1 Animation Principles

**Philosophy**: Subtle (не перевантажувати користувача)
- **Purpose**: Delight + feedback + guide attention
- **Performance**: 60fps, GPU-accelerated
- **Характер**: Smooth, fluid, liquid-like (відповідає Liquid Mercury концепції)

### 8.2 Timing Functions

```css
/* Easing (Material Design style) */
--ease-standard: cubic-bezier(0.4, 0.0, 0.2, 1);
--ease-in: cubic-bezier(0.4, 0, 1, 1);
--ease-out: cubic-bezier(0, 0, 0.2, 1);
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);

/* Duration */
--duration-fast: 200ms;     /* Micro-interactions, button hovers */
--duration-normal: 300ms;   /* Standard transitions, cards */
--duration-slow: 500ms;     /* Page transitions, modals */
```

## 9. TONE & VOICE (Тон і голос)

### 9.1 Brand Voice Attributes

**З аналізу комерційної пропозиції:**

1. **Direct/Прямий** - Говоримо відкрито про проблеми: "Ви виснажені, стосунки під напругою, і бізнес став в'язницею"

2. **Empathetic/Емпатичний** - Глибоке розуміння болів клієнтів: "Ми розуміємо глибоко" (розділ про Пастку експертизи)

3. **Results-Oriented/Орієнтований на результат** - Конкретні цифри: "10-кратна ємність клієнтів", "ROI: 10-30x протягом першого року"

4. **Professional/Професійний** - Технічна точність поєднана з доступністю: "95%+ рівень задоволеності клієнтів"

5. **Motivational/Мотиваційний** - Апелює до аспірацій: "Справжні експерти будують системи. Аматори залишаються вузькими місцями"

### 9.2 Writing Style

**Sentence Structure:**
- Length: Varied (короткі для impact, середні для пояснень)
- Complexity: Mixed (прості для масового appeal, технічні де потрібно)
- Active voice: Strongly preferred

**Word Choice:**
- Technical Terms: Використовуються вибірково з поясненням ("AI-двійник", "GPT-4 Turbo")
- Contractions: Не використовуються в офіційних документах
- Personal Pronouns: "Ви/Ваш" (focus на клієнта), "Ми" (для компанії)

**Formatting:**
- Lists: Активне використання bullet points
- Emphasis: Bold для ключових метрик та результатів
- Call-to-Actions: Command style ("Заплануйте демонстраційний дзвінок")

### 9.3 Tone by Context

## 12. DO'S & DON'TS (Правила)

### 12.1 Logo Usage

**✅ ЩО МОЖНА:**

1. **Використовувати офіційні варіанти**:
   - Vertical, Horizontal, Symbol - згідно контексту
   - Кольоровий на світлому/темному фоні
   - Монохромний для обмежених можливостей друку

2. **Дотримуватись мінімальних розмірів**:
   - Digital: мінімум 32px
   - Print: мінімум 15mm

3. **Зберігати захисну зону**:
   - Вільний простір = висота букви "M"

4. **Використовувати правильні фони**:
   - Кольоровий логотип: білий, світло-сірий фон
   - Білий логотип: градієнт, темні кольори
   - Монохромний: будь-який контрастний фон

**❌ ЩО ЗАБОРОНЕНО:**

1. **НЕ змінювати пропорції** - розтягувати/стискати
2. **НЕ змінювати кольори** - тільки затверджені варіації
3. **НЕ додавати ефекти** - тіні, обводки, градієнти (крім офіційних)
4. **НЕ обертати** логотип
5. **НЕ розміщувати** на складних фонах без підкладки
6. **НЕ порушувати** захисну зону
7. **НЕ використовувати** старі версії логотипу

### 12.2 Colors Usage

**✅ DO:**
- Використовувати color palette консистентно
- Дотримуватись пропорцій 60/30/10
- Забезпечити достатній контраст
- Тестувати кольори в різних контекстах

**Рекомендовані комбінації**:

1. **High contrast (основна)**:
   - Background: `#ffffff`
   - Primary: `#0066FF`
   - Secondary: `#7928CA`
   - Text: `#343a40`

2. **Темна тема**:
   - Background: `#343a40`
   - Primary: `#7de8ff`
   - Secondary: `#945ddf`
   - Text: `#ffffff`

3. **Градієнтна**:
   - Background: `linear-gradient(135deg, #7928CA, #3D25D3, #0066FF)`
   - Text: `#ffffff`
   - Accents: `#7de8ff`

**❌ DON'T:**
- Вводити нові кольори без затвердження
- Використовувати кольори що не проходять accessibility тести
- Надмірно використовувати accent colors

### 12.3 Typography

**✅ DO:**
- Дотримуватись typographic hierarchy
- Використовувати затверджені font weights
- Підтримувати читабельність (line-height 1.5-1.6 для body)

**❌ DON'T:**
- Розтягувати або стискати шрифти
- Використовувати більше 3 розмірів шрифту на одному екрані
- Використовувати Caveat (decorative font) для body text

### 12.4 Imagery & Photography

**✅ DO:**
- Використовувати високоякісні, професійні зображення
- Фокус на технології, люди з пристроями
- Світлі, оптимістичні тони
- Легкий синій фільтр (overlay #0066FF opacity 5-10%)
- Оптимізувати для web performance (WebP з JPG fallback)
- Надавати alt text для всіх зображень

**Пропорції зображень**:
- Hero images: 16:9
- Card images: 4:3 або 1:1
- Avatar: 1:1

**❌ DON'T:**
- Використовувати generic stock photos з водяними знаками
- Надмірно фільтрувати або редагувати
- Використовувати зображення з inconsistent style

### 12.5 Product Positioning

**✓ DO (з Strategic Integration Master + Brand Guidelines):**
- Лідирувати з місійно-орієнтованим меседжем: "Допоможіть 10,000 людям з тією ж якістю"
- Підкреслювати автентичність: "95%+ рівень відповідності особистості"
- Використовувати конкретні метрики: "10-кратна ємність клієнтів", "20 годин/тиждень повернуто"
- Розглядати автоматизацію як апгрейд ідентичності: "Справжні експерти будують системи"

**✗ DON'T (з Strategic Integration Master):**
- Продавати лише "економію часу" (занадто поверхнево)
- Використовувати технічний жаргон без пояснення
- Позиціонувати як "просто чатбот" або "загальний AI"
- Ігнорувати емоційні драйвери (страх заміни, ідентичність)

### 12.2 Messaging

**✓ DO:**

- Використовувати соціальний доказ (відгуки, метрики)

**✗ DON'T:**
