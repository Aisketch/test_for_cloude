### 2.2 Логотип

#### 2.2.1 Концепція логотипу

**Liquid Mercury (Рідкий метал що застиг)**

Це кристалізація системи. Логотип фіксує мить, коли рідина перетворилась у форму.

Ви бачите чітке, готове рішення — результат складної гнучкості всередині. Технології, як рідкий метал, плавно адаптуються до вас, ваших цілей і контексту.

#### 2.2.2 Варіанти логотипу

##### A. Vertical Use (Вертикальне використання)

```
    М
 (символ)
  MIDOS
```

**Застосування:**
- Веб-сайт (головна сторінка, футер)
- Мобільні додатки (екран завантаження)
- Соціальні мережі (аватар профілю)
- Презентації (титульна сторінка)

##### B. Horizontal Use (Горизонтальне використання)

```
М IDOS
```

**Застосування:**
- Email підпис
- Документація
- Презентації (хедер слайдів)
- Друковані матеріали (візитки, листівки)

##### C. Symbol Use (Тільки символ)

```
М
(тільки літера з краплею)
```

**Застосування:**
- Favicon
- App icon
- Watermark
- Малі розміри (менше 32px)

#### 2.2.3 Кольорові варіації логотипу

**1. Повнокольоровий (з металевим ефектом)**
- Основний варіант для цифрових медіа
- Ефект рідкого срібла
- Використання: веб-сайт, додатки, презентації

**2. Градієнтний (бренд-градієнт)**
- На градієнтному фоні (#7928CA → #3D25D3 → #0066FF)
- Білий логотип або контурний
- Використання: маркетингові матеріали, соціальні медіа

**3. Монохромний чорний**
- Чорний логотип на білому/світлому фоні
- Використання: документи, факси, чорно-білий друк

**4. Монохромний білий**
- Білий логотип на темному фоні
- Використання: темна тема UI, відео, презентації

#### 2.2.4 Захисна зона логотипу

**Мінімальна вільна зона:**
- Відстань дорівнює висоті літери "M" у логотипі
- Застосовується з усіх боків
- Ніякі інші елементи не можуть знаходитись у цій зоні

**Мінімальні розміри:**
- Цифрові медіа: мінімум 32px висотою
- Друк: мінімум 15mm висотою

## 3. Типографіка

### 3.1 Шрифтова система

Створюють цілісну й гнучку типографічну систему бренду MIDOS.

#### 3.1.1 Alegreya Sans

**Призначення:** Заголовки, акценти, логотип-супровід

**Характеристики:**
- Повторює риси логотипу й формує візуальні акценти
- Гуманістичний sans-serif
- Відкритий, дружній, технологічний

**Посилання:**
- Google Fonts: [Alegreya Sans](https://fonts.google.com/specimen/Alegreya+Sans)
- Ліцензія: Open Font License

**Використання:**
```css
font-family: 'Alegreya Sans', sans-serif;

/* Приклади */
H1: font-size: 48px; font-weight: 700;
H2: font-size: 36px; font-weight: 700;
H3: font-size: 28px; font-weight: 600;

/* Українська */
Цифровий агент бізнесу
Цифровий ангент бізнесу
Цифровий ангент
```

#### 3.1.2 Inter

**Призначення:** Основний текст, UI елементи, навігація

**Характеристики:**
- Забезпечує читабельність і стабільність
- Нейтральний, чіткий, універсальний
- Оптимізований для екранів

**Посилання:**
- Google Fonts: [Inter](https://fonts.google.com/specimen/Inter)
- Ліцензія: Open Font License

**Використання:**
```css
font-family: 'Inter', sans-serif;

/* Приклади */
Body text: font-size: 16px; font-weight: 400; line-height: 1.6;
Small text: font-size: 14px; font-weight: 400;
Button: font-size: 16px; font-weight: 600;

/* English */
Digital Business Agent
Digital Business Agent
Digital аgent
```

#### 3.1.3 Caveat

**Призначення:** Креативні акценти, емоційні виділення

**Характеристики:**
- Підкреслює креативність
- Додає ритму та емоційної виразності
- Використовується обмежено

**Посилання:**
- Google Fonts: [Caveat](https://fonts.google.com/specimen/Caveat)
- Ліцензія: Open Font License

**Використання:**
```css
font-family: 'Caveat', cursive;

/* Приклади - курсивні акценти */
Цифровий ангент (італіки)
Digital agent (італіки)
```

## 4. Правила застосування

### 4.1 Використання логотипу

#### ✅ ЩО МОЖНА:

1. **Використовувати офіційні варіанти:**
   - Vertical, Horizontal, Symbol - згідно контексту
   - Кольоровий на світлому/темному фоні
   - Монохромний для обмежених можливостей друку

2. **Дотримуватись мінімальних розмірів:**
   - Digital: мінімум 32px
   - Print: мінімум 15mm

3. **Зберігати захисну зону:**
   - Вільний простір = висота букви "M"

4. **Використовувати правильні фони:**
   - Кольоровий логотип: білий, світло-сірий фон
   - Білий логотип: градієнт, темні кольори
   - Монохромний: будь-який контрастний фон

#### ❌ ЩО ЗАБОРОНЕНО:

1. **НЕ змінювати пропорції** - розтягувати/стискати
2. **НЕ змінювати кольори** - тільки затверджені варіації
3. **НЕ додавати ефекти** - тіні, обводки, градієнти (крім офіційних)
4. **НЕ обертати** логотип
5. **НЕ розміщувати** на складних фонах без підкладки
6. **НЕ порушувати** захисну зону
7. **НЕ використовувати** старі версії логотипу

### 4.2 Застосування кольорів

#### Рекомендовані комбінації:

**1. Основна (High contrast):**
```css
Background: #ffffff
Primary: #0066FF
Secondary: #7928CA
Text: #343a40
```

**2. Темна тема:**
```css
Background: #343a40
Primary: #7de8ff
Secondary: #945ddf
Text: #ffffff
```

**3. Градієнтна:**
```css
Background: linear-gradient(135deg, #7928CA, #3D25D3, #0066FF)
Text: #ffffff
Accents: #7de8ff
```

**4. Мінімалістична:**
```css
Background: #f1f1f1
Primary: #0066FF
Text: #343a40
Accents: #7928CA (помірно)
```

#### Пропорції використання:

- **60%** - Основний фон (білий/світло-сірий)
- **30%** - Вторинні елементи (Primary colors)
- **10%** - Акценти (Accent colors)

```css
Card:
  background: #ffffff;
```

### 4.4 Ікони та графіка

**Стиль ікон:**
- Line icons (обведені, не заповнені)
- Товщина лінії: 2px
- Кути: заокруглені (border-radius: 2px)
- Розміри: 16px, 24px, 32px, 48px

**Кольори ікон:**
- Основні: `#343a40` або `#0066FF`
- Неактивні: `#6c757d`
- На темному: `#ffffff`

### 4.5 Фотографія та зображення

**Стиль фотографій:**
- Високоякісні, професійні
- Фокус на технології, люди з пристроями
- Світлі, оптимістичні тони
- Уникати stock-фото з явними водяними знаками

**Обробка:**
- Легкий синій фільтр (overlay #0066FF з opacity 5-10%)
- Контраст: +10-15%
- Чіткість: висока

**Пропорції:**
- Hero images: 16:9
- Card images: 4:3 або 1:1
- Avatar: 1:1

### 4.6 Анімація та переходи

**Принципи:**
- Швидкість: 200-300ms для більшості переходів
- Easing: `cubic-bezier(0.4, 0.0, 0.2, 1)` (Material Design)
- Плавність: завжди використовувати transitions

**Приклади:**
```css
/* Button hover */
transition: all 0.2s ease;

/* Card hover */
transition: transform 0.3s cubic-bezier(0.4, 0.0, 0.2, 1),
            box-shadow 0.3s cubic-bezier(0.4, 0.0, 0.2, 1);

/* Page transitions */
transition: opacity 0.3s ease-in-out;
```

### 4.7 Адаптивність

**Breakpoints:**
```css
Mobile: 320px - 767px
Tablet: 768px - 1023px
Desktop: 1024px - 1439px
Large Desktop: 1440px+
```

**Адаптація логотипу:**
- Mobile: Symbol use (32-48px)
- Tablet: Horizontal use (40-64px)
- Desktop: Horizontal або Vertical (64-96px)

**Типографіка:**
- Mobile: зменшити розміри на 20-30%
- Tablet: стандартні розміри
- Desktop: збільшені заголовки (+10-20%)

## 5. Приклади застосування

### 5.1 Веб-сайт

**Головна сторінка:**
- Hero section: градієнтний фон + білий логотип (vertical)
- CTA кнопка: зелена (#7eeb26)
- Секції: білий фон, акценти Vibrant Blue

**Навігація:**
- Фон: білий/прозорий
- Текст: #343a40
- Активний пункт: #0066FF
- Логотип: horizontal, кольоровий

### 5.2 Мобільний додаток

**Splash screen:**
- Градієнтний фон
- Vertical логотип (центр)
- Анімація: fade in + scale

**Основний екран:**
- Фон: #ffffff або #f1f1f1
- Хедер: градієнт + білий текст

### 5.3 Презентації

**Титульний слайд:**
- Градієнтний фон на всю сторінку
- Vertical логотип (центр)

**Контентні слайди:**
- Білий фон
