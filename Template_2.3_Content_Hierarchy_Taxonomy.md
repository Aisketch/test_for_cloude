## 📝 USAGE INSTRUCTIONS

1. **Audit existing content** before defining structure
2. **Define clear categories** that are mutually exclusive
3. **Keep hierarchy shallow** (3 levels maximum)
4. **Use user language** not internal jargon
5. **Test findability** with real users
6. **Implement progressively** - start with core pages
7. **Validate accessibility** with automated tools and manual testing

---

## ⚠️ CRITICAL REMINDERS

- Content hierarchy affects both UX and SEO
- Proper heading structure is crucial for accessibility
- Schema markup can improve search visibility significantly
- Alt text is required for accessibility and SEO
- Keep content modular for easy updates and translation
- Test readability scores for your target audience
- Monitor content performance and iterate
- Plan for scalability - easy to add new content types
