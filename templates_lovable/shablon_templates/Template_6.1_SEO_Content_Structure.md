## CONTENT OPTIMIZATION GUIDELINES

### On-Page SEO Checklist

Every Page Must Have:
- [ ] Unique meta title (55-60 characters)
- [ ] Unique meta description (150-160 characters)
- [ ] One H1 tag with primary keyword
- [ ] Properly structured H2-H6 headings
- [ ] Primary keyword in first 100 words
- [ ] Keywords in headings (naturally)
- [ ] Internal links with descriptive anchor text
- [ ] External links (if relevant, with appropriate attributes)
- [ ] Image alt text with keywords
- [ ] Optimized image file names
- [ ] Fast loading speed (<3 seconds)
- [ ] Mobile-friendly layout
- [ ] Proper URL structure
- [ ] Schema markup (where applicable)
- [ ] Canonical tag
- [ ] OG tags for social sharing
- [ ] Readable, valuable content

### Keyword Usage Best Practices

Primary Keyword Placement:
- Meta Title: Yes (preferably at start)
- Meta Description: Yes (naturally)
- H1: Yes (exact match or close variation)
- First paragraph: Yes (within first 100 words)
- H2 headings: Some (2-3 times)
- Body content: Natural distribution
- Image alt text: 1-2 times
- URL slug: Yes

Keyword Density:
- Target: 0.5-2%
- Primary keyword: ___ occurrences
- Avoid: Keyword stuffing
- Focus: Natural, readable content

Keyword Variations:
- Use synonyms: _______________
- Use long-tail variations: _______________
- Use question formats: _______________
- Use action verbs: _______________

### Content Length Guidelines

Homepage: 500-800 words
Feature Pages: 1,000-1,500 words
Product Detail: 1,500-2,000 words
Blog Posts: 1,500-3,000 words
About Page: 500-1,000 words
Pricing Page: 500-800 words
Landing Pages: 800-1,200 words

Rationale: Longer content tends to rank better, but quality > quantity

### Readability Standards

Target Audience Reading Level: _______________
Flesch Reading Ease Score: _______________ (60-70 = Standard)
Flesch-Kincaid Grade Level: _______________ (8-10 = Comfortable)

Readability Tactics:
- [ ] Short sentences (15-20 words average)
- [ ] Short paragraphs (2-4 sentences)
- [ ] Bullet points and lists
- [ ] Subheadings every 300 words
- [ ] Active voice (80%+ of sentences)
- [ ] Transition words (30%+ of sentences)
- [ ] Simple vocabulary
- [ ] Avoid jargon (or explain it)

### Anchor Text Strategy

Branded Anchor Text: [Brand Name] (10%)
Exact Match: [Primary Keyword] (15%)
Partial Match: [Keyword Variation] (40%)
Generic: "Learn more", "Read more" (20%)
Naked URL: https://domain.com (5%)
Branded + Keyword: [Brand] [Keyword] (10%)

Avoid:
- Over-optimization
- Same anchor text repeatedly
- "Click here" or generic only
