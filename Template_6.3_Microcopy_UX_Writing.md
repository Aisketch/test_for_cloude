### Writing Principles

Principle 1: Clarity Over Cleverness
- Use simple, direct language
- Avoid jargon unless necessary
- Explain technical terms
- One idea per sentence

Principle 2: User-Focused
- Use "you" and "your"
- Focus on benefits, not features
- Answer "What's in it for me?"
- Anticipate questions

Principle 3: Actionable
- Clear calls to action
- Tell users what will happen
- Remove ambiguity
- Use active voice

Principle 4: Consistent
- Use same terms throughout
- Follow established patterns
- Maintain voice across channels
- Reference style guide

Principle 5: Concise
- Remove unnecessary words
- Get to the point quickly
- Respect user's time
- Mobile-first brevity

## 📝 USAGE INSTRUCTIONS

1. **Establish voice first** - all microcopy flows from brand voice
2. **Write for users** not stakeholders - focus on clarity
3. **Test with real users** - what makes sense to you may confuse others
4. **Keep it concise** - especially for mobile
5. **Be helpful in errors** - don't blame, guide to solution
6. **A/B test CTAs** - small changes can have big impact
7. **Maintain consistency** - create reusable patterns

---

## ⚠️ CRITICAL REMINDERS

- Microcopy has huge impact on conversion rates
- Error messages should never blame the user
- Empty states are opportunities to guide users
- Button text should be action-oriented and specific
- Form labels must be clear without helper text
- Success messages reinforce positive behavior
- Loading states reduce perceived wait time
- Consistency builds user confidence
- Accessibility matters - clear language helps everyone
- Each language may need adaptation, not just translation
